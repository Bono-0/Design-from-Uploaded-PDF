# STILL ESSENCE

## Brutalist Editorial Photography Website

Design and prototype a complete, high-end photography website for **Still Essence**, a Johannesburg-based photography studio specialising in portraits, lifestyle, events and creative/editorial photography.

The website should feel like a **brutalist editorial photography publication combined with a contemporary creative studio portfolio**. It should not look like a conventional photographer template, wedding photography website, SaaS website or generic portfolio.

The overall experience should feel raw, intentional, artistic, cinematic and slightly unconventional. The photography should remain the hero of the experience, with typography, layout and motion supporting the images rather than competing with them.

---

# 1. DESIGN DIRECTION

Use a **Modern Brutalist / Raw Editorial** aesthetic.

The visual language should combine:

* Brutalist web design
* Contemporary fashion editorials
* Independent photography publications
* Art direction
* Raw campaign aesthetics
* Industrial graphic design
* Experimental editorial layouts
* High-end photography portfolios

The website should feel deliberately constructed rather than perfectly symmetrical.

Use **asymmetrical grids, oversized typography, unexpected image positioning, large negative spaces, hard edges and utilitarian interface elements**.

Avoid:

* Generic photography templates
* Rounded SaaS cards
* Excessive gradients
* Glassmorphism
* Soft shadows
* Excessive rounded corners
* Generic AI-generated website layouts
* Corporate design language
* Excessively decorative animations
* Stock photography aesthetics

The website should feel like someone with a strong creative direction designed it.

---

# 2. COLOUR SYSTEM

Primary background:

**#E3E2DE**

Deep primary text:

**#1B0E0D**

Primary accent:

**#C72A09**

Neon interaction accent:

**#31EF07**

Use the beige and deep brownish-black as the dominant palette.

Burnt red should be used selectively for important actions, labels, numbers and visual interruptions.

Neon green should primarily appear during interactions, hover states, active states and small interface details.

Do not allow the neon green to dominate the page.

The overall appearance should remain predominantly monochromatic and editorial.

---

# 3. NOISE / GRAIN

Apply a persistent subtle noise texture over the entire website.

Use an SVG fractalNoise texture with approximately:

**opacity: 0.08**

**mix-blend-mode: multiply**

The texture should be subtle enough that it does not interfere with readability.

It should create a tactile printed-editorial feeling across the entire interface.

---

# 4. TYPOGRAPHY

Use:

**Clash Grotesk**

for:

* Hero typography
* Major headings
* Page titles
* Large numbers
* Editorial statements
* Section headings
* Important visual text

Display typography:

**font-weight: 700**

**letter-spacing: -0.04em**

**line-height: 0.85**

Headings should be extremely large and tightly tracked.

Use **General Sans** for:

* Body copy
* Navigation
* Buttons
* Descriptions
* Captions

Use a **monospace font** for:

* Image metadata
* Dates
* Locations
* Project numbers
* Technical information
* Small labels
* Photography specifications

Typography should create strong contrast between expressive editorial headlines and functional technical information.

---

# 5. LAYOUT SYSTEM

Use an asymmetrical editorial grid.

Do not centre everything.

Use:

* Full-width imagery
* Offset images
* Oversized typography
* Narrow text columns
* Wide image fields
* Cropped photography
* Overlapping elements
* Large empty spaces
* Vertical labels
* Small technical metadata
* Unexpected alignment

Use a strong underlying grid but deliberately break it in certain sections.

Photography should frequently extend beyond conventional column boundaries.

Use large margins on desktop.

On mobile, maintain the editorial character rather than simply stacking everything into generic cards.

---

# 6. IMAGE DIRECTION

Photography is the most important part of the website.

Use high-contrast imagery.

Many images should appear:

* Black and white
* Slightly desaturated
* High contrast
* Grainy
* Cinematic
* Editorial
* Raw

Do not apply the same treatment to every image. Allow selected photographs to retain colour where it creates visual impact.

Images should feel like photographs from a fashion editorial or independent photography publication.

On hover, images should smoothly scale to approximately:

**1.05**

Use image containers with overflow hidden.

Keep transitions swift and purposeful.

---

# 7. INTERACTION DESIGN

Animations should be quick, deliberate and functional.

Avoid slow, unnecessary animations.

Use:

* Image scale on hover
* Text reveals
* Scroll-triggered image reveals
* Slight image translations
* Clip-path reveals
* Horizontal movement where appropriate
* Navigation transitions
* Editorial page transitions

Links should use a custom hover animation.

Create a **2px neon-green underline** that scales horizontally from:

**scaleX(0) → scaleX(1)**

Use:

**cubic-bezier(0.165, 0.84, 0.44, 1)**

The underline should originate from the left and animate beneath the link.

Buttons should feel utilitarian rather than decorative.

Use hard edges and strong typography.

# 19. RESPONSIVE DESIGN

The website must be fully responsive.

Desktop should use the full editorial grid.

Tablet should simplify the grid while retaining asymmetry.

Mobile should not become a generic stacked website.

Maintain:

* Oversized typography
* Strong image hierarchy
* Editorial spacing
* Horizontal scrolling where appropriate
* Large photography
* Technical metadata
* Brutalist navigation

Ensure all text remains readable and buttons remain easy to use.

---

# 20. MICRO-INTERACTIONS

Use neon green #31EF07 for small interaction moments.

Examples:

Navigation hover
Link underline
Image hover metadata
Cursor interactions
Active portfolio filters
Button hover
Menu transitions

Do not use neon green as a background for large sections.

It should feel like an unexpected flash of colour.

---

# 21. CURSOR / HOVER BEHAVIOUR

On desktop, experiment with a subtle custom cursor.

When hovering over a portfolio image, the cursor can change to:

**VIEW ↗**

or:

**OPEN PROJECT**

Use the neon green accent sparingly.

Do not make the cursor distracting.

---

# 22. SCROLL EXPERIENCE

Scrolling should reveal the photography progressively.

Use scroll-triggered:

* Image reveals
* Typography reveals
* Slight image scaling
* Horizontal movement
* Text transitions

The first screen should be immediate and impactful.

Animations should generally be between approximately 300ms and 700ms.

Avoid excessive parallax.

The website should feel fast.

---

# 23. ACCESSIBILITY

Maintain strong contrast between:

**#E3E2DE**

and

**#1B0E0D**

Ensure all interactive elements have clear hover and focus states.

Images should include meaningful alt text.

Do not rely solely on colour to communicate information.

Buttons should remain clearly identifiable.

---

# 24. OVERALL BRAND FEEL

The final website should communicate:

**RAW**

**CINEMATIC**

**HUMAN**

**EDITORIAL**

**INTENTIONAL**

**YOUTHFUL**

**PREMIUM**

**CREATIVE**

It should feel like Still Essence is a **creative photography studio with a distinct point of view**, rather than simply a photographer displaying a collection of images.

The final visual impression should be:

**An independent photography publication meets a modern creative studio.**

The website should make someone want to explore the photographs first, understand the person behind them second, and book a shoot third.
